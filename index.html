R01

Pipeline ETL & BI: Faturamento de Notas Fiscais (Dunder Mifflin)

  • Power BI
  • Python (pdfplumber & pyodbc)
  • SQL Server (T-SQL)
  • DAX (Parâmetros de Campo)
  • Figma (UI/UX)

Projeto End-to-End de Engenharia e Análise de Dados simulando a operação comercial da Dunder Mifflin Paper Company. O pipeline automatiza a geração de 250 DANFEs em PDF, extrai cabeçalhos, impostos e linhas de itens via Python (pdfplumber e Regex) e realiza carga incremental no SQL Server (pyodbc). No Power BI, o painel conta com interface desenhada no Figma, tratamento de granularidade entre nota e produtos via DAX (SUMX e SUMMARIZE) e Parâmetros de Campo para alternar métricas dinamicamente nos rankings de clientes e vendedores.

Análise Financeira: Fluxo de Caixa Corporativo

  • Power BI
  • DAX (Parâmetros de Campo)
  • Modelagem Financeira
  • UI/UX

Painel executivo focado no controle de Fluxo de Caixa e monitoramento da saúde financeira do negócio. A modelagem classifica e consolida transações de Recebimentos e Pagamentos para apurar o Saldo Líquido real da operação ao longo do tempo. O projeto inclui o uso avançado de DAX com Parâmetros de Campo (Field Parameters), garantindo interatividade dinâmica para a diretoria cruzar dados bancários e formas de pagamento em um único visual, apoiando a tomada de decisão estratégica.
